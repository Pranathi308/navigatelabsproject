# **App Name**: Vision Weaver

## Core Features:

- Text-to-Image Generation: Generates an image from a text prompt using a Large Language Model tool, such as DALL·E or Stable Diffusion.
- Image-to-Text Generation: Generates a text description from an uploaded image using a Large Language Model tool such as Gemini Vision API or Google Cloud Vision API.
- Text Input: Displays a text input area for text-to-image prompts.
- Image Upload: Provides an upload button for image-to-text functionality.
- Image Display: Displays generated images.
- Caption Display: Displays the text caption for images.

## Style Guidelines:

- Primary color: Vibrant blue (#5DADE2) to represent clarity and vision.
- Background color: Light blue (#EBF4FA), subtly tinted from the primary, to create a clean, unobtrusive backdrop.
- Accent color: Analogous violet (#8E44AD) to draw attention to interactive elements without clashing.
- Body and headline font: 'Inter', a grotesque sans-serif, for a modern and readable interface.
